* **How to Update Note Type via Anki-Connect**
* Anki-Connect does not offer a single `updateNoteType` API call. You must update card templates and CSS styling using two separate actions: **`updateModelTemplates`** and **`updateModelStyling`**.


* **1. Update Front & Back Card Templates (`updateModelTemplates`)**
* Sends updated HTML templates for card fronts and backs.
* **Payload Structure:**
```python
import requests

url = "http://127.0.0.1:8765"
payload = {
    "action": "updateModelTemplates",
    "version": 6,
    "params": {
        "model": {
            "name": "Japanese Note type (Sentence card by Default)",
            "templates": {
                "Card 1": {
                    "Front": "YOUR_FRONT_HTML_HERE",
                    "Back": "YOUR_BACK_HTML_HERE"
                }
            }
        }
    }
}
response = requests.post(url, json=payload).json()
print("Templates update response:", response)

```




* **2. Update Card CSS Styling (`updateModelStyling`)**
* Updates global CSS rules for all cards under the note type.
* **Payload Structure:**
```python
payload = {
    "action": "updateModelStyling",
    "version": 6,
    "params": {
        "model": {
            "name": "Japanese Note type (Sentence card by Default)",
            "css": "YOUR_CSS_STYLING_HERE"
        }
    }
}
response = requests.post(url, json=payload).json()
print("Styling update response:", response)

```




* **Crucial Key Names to Avoid API Errors:**
* Parameter root key must be **`"model"`** containing **`"name"`** (e.g., `params.model.name`).
* Using `"modelName"` directly inside `params` causes an API keyword exception.
